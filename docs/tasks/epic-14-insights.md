# Epic 14 — Insights

**Milestone:** 4 — Portfolio Intelligence
**Status:** todo

## Overview

Implement technology summaries, portfolio health metrics, reusable component discovery, and activity timeline to provide portfolio-wide insights.

---

## Story 14.1: Technology Summaries

**Status:** todo
**Size:** M
**Blocked by:** 12.5

**User Story:**
As a user, I want technology summaries so that I can see my tech stack across all projects.

**Acceptance Criteria:**
- Aggregates technologies across portfolio
- Shows project count per technology
- Shows co-occurrence (tech used together)
- Trend over time (new projects using tech)

---

## Story 14.2: Portfolio Health

**Status:** todo
**Size:** M
**Blocked by:** 10.3

**User Story:**
As a user, I want portfolio health metrics so that I can identify projects needing attention.

**Acceptance Criteria:**
- Identifies stale projects (no recent commits)
- Identifies projects without analysis
- Identifies outdated analyses
- Identifies projects without documentation
- Actionable recommendations per issue

## Story 14.3: Reusable Implementation Discovery

**Status:** todo
**Size:** L
**Blocked by:** 13.2

**User Story:**

**Acceptance Criteria:**

- Filters by technology or feature type

## Story 14.4: Activity Timeline

**Status:** todo
**Size:** M
**Blocked by:** 3.1

**User Story:**
As a user, I want an activity timeline so that I can see when I worked on different projects.

**Acceptance Criteria:**
